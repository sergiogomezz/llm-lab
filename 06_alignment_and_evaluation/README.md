# Alignment and evaluation

Status: planned.

Learn how models are trained toward preferred behavior and how to evaluate
whether a change improves the intended outcomes.

## Topics

- [ ] Understand reinforcement learning from human feedback (RLHF).
- [ ] Study direct preference optimization (DPO).
- [ ] Study group relative policy optimization (GRPO).
- [ ] Learn LLM evaluation methodology and common benchmarks.
- [ ] Explore reasoning models.
- [ ] Study safety techniques and guardrails.

Define evaluation questions and held-out examples before comparing models or
training methods. Record prompt formats, settings, results and limitations;
distinguish observed behavior from claims about how a model was trained.

Add notebooks or small experiments as this stage begins. Check off topics only
after verification and recorded conclusions.
